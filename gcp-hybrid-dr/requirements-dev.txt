# Linter, PINNED EXACTLY.
#
# This is not caution for its own sake. The local ruff was 0.16.4 and
# reported the code as clean; CI installed the latest ruff and reported
# 11 errors on the SAME code, because the newer version flags UP017
# (`datetime.timezone.utc` -> `datetime.UTC`) once the target version
# is 3.11+. A linter whose default behaviour can change under you
# cannot be a gate.
#
# The rule set is now declared explicitly in pyproject.toml, so the
# behaviour is recorded in the repo rather than inherited from a
# default. The pin is belt and braces: it also freezes the rule
# implementations, so a patch release cannot change the verdict.
#
# Bump deliberately: install the new version locally, run
# `ruff check src/ tests/`, and only then update this line.
ruff==0.16.4
